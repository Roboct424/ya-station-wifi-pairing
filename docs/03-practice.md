# Практика: подключение колонки к Wi-Fi

## Что нужно

* Колонка в **режиме настройки** (см. ниже).
* Устройство с динамиком: ноутбук, телефон, любой плеер.
* Знать SSID и пароль (до 255 байт в UTF-8 каждый).
* 10–60 секунд тишины рядом с колонкой.

Ни аккаунта, ни приложения, ни интернета, ни рута.

---

## Шаг 1. Ввести колонку в режим настройки

Режим настройки — это состояние, в котором колонка ещё «ничья»: пульсирует
световое кольцо и она предлагает настроиться.

Варианты:

1. **Новая или сброшенная колонка** — включает режим настройки сама после
   первого включения / сброса.
2. **Уже настроенная колонка** — сбросить кнопкой (на Station Mini 2 — удержание
   кнопки сброса), либо, если есть доступ, перезапустить приложение
   в режиме настройки.

> Акустический декодер работает **не всегда**, а в окне после старта режима
> настройки. Если колонка давно «висит» в этом состоянии, звук может
> восприниматься как обычная речь — отсюда ответ «не расслышала».
> Надёжнее всего: свежая загрузка/сброс и звук в первые минуты.

## Шаг 2. Проиграть код

### Вариант A: командная строка (ПК)

```bash
pip install numpy    # sounddevice не обязателен (winsound/paplay/aplay/afplay)
python tools/pair_by_sound.py --ssid "YaRig" --password "11111111"
```

По умолчанию: 3 повтора с паузой 9 с, громкость 0.5.

Если колонка «не слышит» первые кадры, добавьте предстарт 1–4:

```bash
python tools/pair_by_sound.py --ssid "YaRig" --password "11111111" --preroll 2
```

Это повтор преамбулы перед кадром: декодер успевает открыть микрофонный тракт.
Каждый повтор — +160 мс, лишние безвредны.

### Вариант B: автоматический режим

```bash
python tools/provision.py --ssid "YaRig" --password "11111111"
```

Играет, перебирает громкость `0.5 → 0.35 → 0.65 → 0.8` и сам определяет успех
по появлению новой записи в ARP-таблице.

Если в сети несколько устройств, укажите MAC-префикс колонки:

```bash
python tools/provision.py --ssid "YaRig" --password "11111111" --mac-prefix b8-87-6e
```

### Вариант C: графическое приложение (ПК)

```bash
python tools/provision_gui.py
```

Поля SSID/пароль/тип, ползунок громкости, предстарт 0–4, кнопки «Играть»,
«Цикл до подключения», «Сохранить WAV».

Единое окно с двумя вкладками («Звук» и «Wi-Fi (AP)»):

```bash
python tools/station_pairing.py gui
```

### Вариант D: телефон

`tools/sound_code.html` — один файл, работает в браузере (Chrome/Safari):

```bash
python -m http.server 8000     # в папке tools/
# на телефоне: http://<IP-ноутбука>:8000/sound_code.html
```

или скиньте файл на телефон и откройте локально. Громкость телефона — на максимум.

### Вариант E: APK

`android/StationPairing.apk` — то же самое в виде приложения (WebView, офлайн),
плюс вкладка «Wi-Fi (AP)»: телефон подключается к точке доступа устройства и
отправляет креды по HTTP. Единственное разрешение — `INTERNET` (локальная сеть).
Сборка из исходников — `android/README.md`.

## Шаг 3. Проверить результат

Признаки успеха:

* колонка перестала пульсировать и говорит, что подключилась;
* в логе роутера/DHCP появилось новое устройство;
* `arp -a` показывает новый MAC (у Station Mini 2 префикс `b8-87-6e`);
* на ПК `provision.py` сам печатает «ГОТОВО: колонка в сети …».

После приёма кода колонка **глохнет на 5–9 секунд** — в это время она
подключается к Wi-Fi. Повторять звук в этот момент бессмысленно.

---

## Громкость — самое важное

Рабочее значение: **0.5** от полной шкалы (файл генерируется с этой амплитудой).

Почему нельзя громче:

* микрофон колонки перегружается, в сигнале появляются искажения;
* RS-блок держит только 2 ошибки на 15 нибблов;
* при перегрузе ошибок больше — колонка **молча** отбрасывает кадр.

В её логе это выглядит так:

```
Protocol version candidate: 0
Source protocol version is: 0
reed_solomon_decoder.cpp:101  Error locator degree does not match number of roots
reed_solomon_decoder.cpp:111  Bad error location: -1
```

Слишком тихо — тоже плохо: колонка не выделит тоны из шума.

## Если не получается

| Симптом | Что делать |
|---|---|
| «Не расслышала» | уменьшить громкость до 0.35–0.5, поднести ближе (0.3–1 м), убрать шум |
| Молчит | проверить, что колонка в режиме настройки; перезагрузить её и повторить сразу |
| Слышно, но сеть не появляется | проверить пароль; для скрытой сети — тип `4`; для открытой — тип `5` |
| Успех был, но сеть не та | колонка запомнила последнюю; повторите с нужным SSID |
| Несколько колонок рядом | настраивайте по одной, остальные выключите |
| Ноутбук «не видит» устройство вывода | указать `--device <индекс>` (список: `python -c "import sounddevice;print(sounddevice.query_devices())"`) |
| Телефон тихий | выкрутить громкость мультимедиа, снять чехол с динамика |

---

## Ограничения метода

* Работает только в режиме настройки.
* Не меняет пароль «на лету»: чтобы перевыдать другие креды, колонку нужно снова
  перевести в режим настройки.
* Не сообщает о результате напрямую — успех определяем по сети.
* Скрытые сети: колонка получает только хэш имени, поэтому в некоторых прошивках
  скрытые сети могут не подхватываться (проверяйте).
